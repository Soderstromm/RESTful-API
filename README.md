# 🌐 Микросервисная система управления заказами (RESTful API)

Учебный проект, демонстрирующий принципы проектирования и разработки распределенных микросервисных архитектур на базе экосистемы Spring. Приложение разделено на независимые доменные сервисы, взаимодействующие друг с другом через декларативные REST-клиенты.

## 🏗 Архитектура системы

Система реализует паттерн **BFF (Backend for Frontend)** и состоит из следующих независимых модулей:

1. **`bff-service` (API Gateway / Aggregator)**  
   Единая точка входа для клиента. Принимает запросы, обращается к нижележащим сервисам, агрегирует данные и возвращает клиенту оптимизированный ответ, скрывая внутреннюю сложность системы.
2. **`user-service`**  
   Отвечает за управление данными пользователей, их регистрацию и базовую аутентификацию.
3. **`order-service`**  
   Реализует бизнес-логику создания, обработки, изменения статуса и хранения заказов.
4. **`config-server`** *(опционально, если есть в проекте)*  
   Централизованное управление конфигурациями для всех микросервисов из единого Git-репозитория.

## 🛠 Технологический стек

| Категория | Технологии |
| :--- | :--- |
| **Язык** | Java 17+ |
| **Фреймворк** | Spring Boot 3, Spring Web, Spring Data JPA |
| **Микросервисы** | Spring Cloud, OpenFeign (межсервисное взаимодействие) |
| **База данных** | PostgreSQL (паттерн Database-per-service) |
| **Сборка** | Maven |
| **Инфраструктура** | Docker, Docker Compose |
| **Документация** | Swagger (OpenAPI 3) |
| **Тестирование** | JUnit 5, Mockito |
